# Apple Portfolio

A responsive developer portfolio with Liquid Glass styling, animated projects, social links, and System, Light, and Dark themes.

Built with React, TypeScript, and Vinext. Requires Node.js 22.13 or newer.

## Run

```bash
npm ci
npm run dev
```

## Customize

Edit `lib/profile.ts` for your details and projects. Put your images and résumé in `public/`.

## Check and build

```bash
npm run check
npm run build
```
